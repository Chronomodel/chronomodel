ChronoModel Project
"https://www.chronomodel.com"
version 4.0.0
2026-11-18

ChronoModel is a software for constructing chronological models of
archaeological and geological data using Bayesian statistics
(Events, Phases, temporal constraints and time-dependent curves).

The package contains:
	ChronoModel        graphical application
	ChronoModel_Bash   batch computation of several ChronoModel projects
